# RONUP - By Publimatec
## Sistema de Escaleteas, Guiones, Prompter para Producción TV y eventos.

## Cómo levantar el entorno local
Este proyecto usa Laravel Sail. Para levantarlo, usá:
`./vendor/bin/sail up -d`

## Puertos que ocupa
- Web: 80 (invisible por defecto... localhost.)
- Base de datos (PostgreSQL): 5432
- Redis: 6379
